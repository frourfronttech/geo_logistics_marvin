# Navigate App - Backend

This is the backend for the Navigate app, built with Node.js and Express.

## Getting Started

1.  Install dependencies:
    ```
    npm install
    ```
2.  Create a `.env` file in the root directory and add the following environment variables:
    ```
    PORT=3000
    ```
3.  Start the server:
    ```
    node src/index.js
    ```
